# Protótipo de baixa fidelidade (Etapa 2 do PIC)

Telas do Vínculo em tons de cinza, sem cor e sem identidade visual, para discutir **estrutura e fluxo** antes do visual final. Foram geradas a partir do protótipo funcional (mesmas telas, mesmos dados fictícios).

| Arquivo | Tela | Perfil |
|---|---|---|
| `01-entrar.png` | Entrar (login, avisos de LGPD e sessão) | Público |
| `02-fila-de-espera.png` | Fila de espera com prioridade e alerta de duplicidade | Coordenação |
| `03-painel-estagiario.png` | Painel do estagiário (pendências do dia) | Estagiário |
| `04-prontuario-evolucoes.png` | Prontuário — aba Evoluções (rascunho → validação) | Estagiário |
| `05-agenda-semana.png` | Agenda — visão da semana | Estagiário |
| `06-triagem.png` | Formulário de triagem com validadores | Coordenação |
| `07-indicadores.png` | Indicadores da clínica | Coordenação |
| `08-meus-dados.png` | Minha conta — dados, termos e pedidos LGPD | Estagiário |

A navegação entre essas telas está no diagrama de navegação em [`../diagramas.md`](../diagramas.md).
